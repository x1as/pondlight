# PONDLIGHT — project conventions

* Engine: **Godot 4.7.2**, GDScript, Compatibility renderer. Editor: `%LOCALAPPDATA%\Microsoft\WinGet\Packages\GodotEngine.GodotEngine_Microsoft.Winget.Source_8wekyb3d8bbwe\Godot_v4.7.2-stable_win64_console.exe`.
* Authority order for design: owner corrections → Steam-analyst corrections → master prompt (see `DESIGN.md`).
* Pixel rules: 640×360, integer scale, nearest, whole-pixel coordinates. Follow `ART_BIBLE.md`. Never add default-looking Godot UI — use `UIKit`.
* **No balance numbers in code.** Content and tuning live in `pondlight/data/*.json` (read through the `Data` autoload).
* Pure rules go in `scripts/core/` (no nodes) so they stay unit-testable. Scenes/nodes are built in code; `.tscn` files are thin roots.
* Typed GDScript; tabs; `class_name` for reusable classes; signals between systems. Use typed `for x: T in` loops when inferring from untyped arrays.
* Every economy mutation saves immediately (no duplicate sales/claims). Save format changes → bump `SAVE_VERSION` and extend `_migrate`.
* Quit only through `Save.quit_game()` (saves, stops audio, avoids leaked playbacks).
* Before finishing any change: `run_tests.bat` must report 0 failures; for visual changes take QA screenshots
  (`Godot --path pondlight -- --shot=<png> --scene=game --save_dir=user://qa/ ...`, see README) and look at them.
* Assets are regenerated by `tools/art/*.py` and `tools/audio/gen_audio.py`; edit the generators, not the PNG/WAV outputs.
* SpriteCook art lives in `pondlight/assets/art/spritecook/` (raw in `_raw/`, ids in `spritecook-assets.json`) and is cleaned by `tools/art/polish_spritecook.py`; `UIKit.fish_tex` prefers it over procedural fish. Animations are expensive (~20 credits each) — check the balance first.
* Text: every player-facing string goes through `UIKit.T()` (UIKit.label/button/pop/toast already do). Format strings are translated *before* `%`. New strings need an entry in `pondlight/data/locale/ru.json`; the pixel font (`tools/art/gen_font.py`) contains Latin + Cyrillic.
* Buttons are `UIButton` (`UIKit.button`): set text via `.caption`, sizes via `set_min_size`/`set_min_width` (never `custom_minimum_size`, never anchors on their children).
* QA must never change the player's real `settings.cfg`; use `--lang=` / `--notut=1` flags instead.
* Release: `build_release.ps1` (runs tests first). Build output stays in `build/`.
