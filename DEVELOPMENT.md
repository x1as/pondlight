# PONDLIGHT — development notes

Player-facing overview: [README.md](README.md).

A cozy, skill-based pixel-art fishing game for PC (Steam target). Native **Godot 4.7.2** project,
GDScript, Compatibility renderer, 640×360 pixel canvas with integer scaling. Fully offline.

## Play

| What | How |
|---|---|
| Release build (Windows x64) | `build\windows\Pondlight.exe` (single file, PCK embedded) |
| From source | `run_dev.bat` (uses Godot 4.7.2 installed by winget) |
| Linux build | `build/linux/Pondlight.x86_64` (exported, not run-tested) |

Controls — mouse: hover the pond, **hold LMB** to charge a cast, release in the green zone; on the bite press LMB;
in the fight **tap** when the needle is in the green zone, **hold** to reel, **let go during SURGE**. RMB reels in.
Languages: English and Russian (auto from the OS, switch in Settings).
New players get a guided first catch with Old Croak the frog. Talents live in the Shop's Talents tab, trophies in the Trophy Cabinet (cup button).
Every catch is sold at once - or ridden on the **Tide of Fortune** (stop the bobber on x0..x3 waves, up to 3 times).
Also: Captain's Orders (HUD), Feeding Frenzy on streaks, 1% Prismatic fish, fish traps that fill while the game is closed.
Trends and forecast: [SUCCESS_FORECAST.md](SUCCESS_FORECAST.md). Friends playtest: `build/playtest/PONDLIGHT_playtest_v0.6.zip`. Publishing: [STEAM_RELEASE_GUIDE.md](STEAM_RELEASE_GUIDE.md). Trailer: [TRAILER_PLAN.md](TRAILER_PLAN.md).
Four waters: Willow Pond, Frostmere Lake, Emerald Delta, Leviathan Trench (the Kraken and the Megalodon live in its far Abyss).
Keys: `Space` action, `F` habitat view, `C` codex, `U` shop, `M` map, `J` journal, `Q` bait, `Esc` pause.
Gamepad: stick/D-pad aims the cell cursor, `A` action, `B` cancel, `Y` codex, `LB/RB` shop/map, `Back` bait, `Start` pause.
All menus are gamepad-navigable.

## Build & test

```bash
powershell -ExecutionPolicy Bypass -File build_release.ps1
```
Imports, runs the 386-check test suite (aborts on failure) and exports `build/windows/Pondlight.exe`. Add `-Linux` for the Linux export.

```bash
run_tests.bat
```
Headless tests (`pondlight/tests/test_runner.gd`): every script compiles, rarity anchors exact at L1/5/10/15/20 (L20 = 5/45/50), smooth monotone curve, capped Luck,
species-independent mastery, 8×6 habitat grids and per-habitat odds, rod/line stability under spam and buffered presses, no fish sprites in ponds,
cell odds & catchability of all 12 species, valuation, fight bots (skilled human / idle / button-masher, starter vs maxed gear),
economy (no double sale, no double daily claim), progression & Frostmere unlock, save/load/backup recovery/migration,
and a 30-player balance simulation (median ≈ 32 min of efficient play to unlock Frostmere).

QA screenshot mode (used for visual review; works on the exported exe too):
```bash
Pondlight.exe -- --shot=C:/tmp/shot.png --scene=game --pond=frostmere --hour=0.95 --weather=snow --demo=catch --save_dir=user://qa/
```
`--demo=hover|charge|wait|bite|fight|catch`, `--panel=shop|shop_tip|talents_tip|codex|map|journal|settings|pause|catch|treasure|tide|prismatic|frenzy|cinematic|welcome|trophies|celebrate|golden|pops`, `--gear=1..10` sets every slot's tier, `--overlay=1` habitat view, `--tour=1` presses every menu button.
`--save_dir` keeps QA runs away from the real save.

## Regenerating assets

All art and audio are original and generated by scripts (Python 3.11 + Pillow, no other deps):
```bash
cd tools/art && python gen_world.py && python gen_wild.py && python gen_fish.py && python gen_font.py && python gen_ui.py
python polish_spritecook.py   # re-polishes the SpriteCook downloads in assets/art/spritecook/_raw (ids in spritecook-assets.json)
cd tools/audio && python gen_audio.py        # "wild" = only the Delta/Trench music and ambience
```

## Layout

```
pondlight/              Godot project (only this goes into builds)
  data/*.json           ALL content & balance (fish, ponds/cells, equipment, bait, rarity, fight, economy, achievements)
  scripts/autoload/     Data, Settings(input+audio buses), Platform(Steam layer), Save, Economy, Progression,
                        Achievements(+daily), Clock(time/weather), Audio
  scripts/core/         Pure rules: RarityTable, FishSelector, PlayerStats, Valuation, CastModel, FightModel
  scripts/world/        PondView (diorama), RodRig (rod/line/bobber), FishingController, FxLayer, WeatherFx, CellCursor
  scripts/ui, screens/  UIKit theme, HUD, fight panel, cast meter, menus, main menu, game screen
  assets/               art (world/fish/ui/fx), audio (sfx/music/ambient), font, shaders
  tests/                headless test runner
tools/art, tools/audio  asset generators
build/                  release output (not source)
```

Save file: `%APPDATA%\Godot\app_userdata\Pondlight\save.json` (+ `save.bak.json`), settings in `settings.cfg`.
